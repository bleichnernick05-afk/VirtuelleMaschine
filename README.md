# VirtuelleMaschine
Bevor Sie eine VM Box herunterladen, stellen Sie sicher, dass die VM in Ihrer UEFI/BIOS-Einstellung aktiviert ist

Laden Sie nun eine Oracle VM-Box herunter
Laden Sie als nächstes eine Windows-ISO-Datei herunter
starte deine VM
gehe auf Neu
Gib deiner VM einen Namen und gebe bei ISO Abbild deiner heruntergeladenen ISO-Datei ein
Entferne das Häkchen bei unbeaufsichtigter Installation und gehe anschließend auf Fertigstellen
VM starten
Stelle als deine nächste gewünschte Sprache ein
Jetzt Installation
weiter mit „Ich habe keinen Product-Key
Windows 10 Pro
Lizenzbedingungen bestätigen
Benutzerdefiniert: nur Windows installieren (für fortgeschrittene Benutzer)
Nun schaut dein Bild so aus -> weiter
Dein Windows wird nun Installiert
Nach der Installation müssen Sie nun noch einige Einstellungen vornehmen
In den nächsten 2 Schritten stellst du nun die gewünschte Sprache ein
Wenn Sie möchten, können Sie noch ein zusätzliches Tastenlayout hinzufügen oder den Schritt überspringen
weiter mit persönlicher Verwendung einrichten
Erstelle ein Konto oder gib deine E-Mail an
Stecken Sie den Sicherheitsschlüssel in den USB-Anschluss, können Sie ihn abbrechen und sich einen Code zusenden lassen
Geben Sie den Code, der ihnen zugesandt wurde
Erstellen Sie einen Pin
Nun kommen noch ein paar Einstellungen, die sie vornehmen müssen
Nachdem Sie mit den Einstellungen fertig sind, bekommen Sie ein „Hallo“ und das es noch einige Minuten dauern kann
Nun können sie viel Spaß haben
